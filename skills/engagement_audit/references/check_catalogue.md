# Engagement check catalogue

| ID | Check | Deterministic evidence |
|---|---|---|
| EN-01 | Primary CTA presence | High-intent page has no extracted actionable CTA |
| EN-02 | CTA reachability | Important CTA target returns an error/unreachable status |
| EN-03 | CTA clarity | CTA text and target purpose are materially mismatched |
| EN-04 | Value proposition | High-intent page lacks directly extractable offering context |
| EN-05 | Decision information | Required decision facts are absent |
| EN-06 | Contact/action path | Core service has no discoverable appropriate action route |
| EN-07 | Form actionability | Important form lacks purpose, submit control, or required target |
| EN-08 | Follow-up path | Journey requires follow-up information but no useful path is found |
| EN-09 | Stable direct URL | Important action depends on opaque interaction without direct target |
| EN-10 | Content/action consistency | Page promise and destination purpose materially differ |
| EN-11 | AI-readable action context | Important action has no equivalent textual context |
| EN-12 | Conversion-path completeness | Required journey step is missing |

Do not classify visual style, aesthetics, or subjective UX preference as a finding without deterministic evidence.
